# חבילת העברה ל-Claude Code — תקין

## איך משתמשים
1. פותחים תיקייה חדשה ריקה לפרויקט ומחלצים לתוכה את הקובץ.
2. פותחים בה את Claude Code (`claude` בטרמינל).
3. מדביקים את התוכן של `PROMPT.md` כהודעה הראשונה.
4. מאשרים את התוכנית שהוא מציג, וממשיכים שלב אחרי שלב לפי `SPEC.md`.

## מה יש כאן
| קובץ | תפקיד |
|---|---|
| `PROMPT.md` | ההודעה הראשונה להדבקה |
| `CLAUDE.md` | כללים קבועים שClaude Code קורא בכל סשן |
| `SPEC.md` | אפיון מלא: מסכים, נתונים, מנוע סריקה, שלבים, החלטות פתוחות |
| `design/tokens.css` | צבעים, פונט, מידות |
| `design/reference/` | 7 קבצי העיצוב מהקנבס |
| `content/sample-report.json` | דוח לדוגמה |

## לפני שמגיעים לשלבים המתקדמים, כדאי להחליט
- ספק סליקה וחשבוניות
- איפה ירוץ הסורק (שרת עם דפדפן)
- מסד נתונים וספק מייל
- האם להשתמש ב-Claude API לניסוחים חלופיים
- כמה אתרים כלולים במסלול המשרדים, ומע"מ
- בדיקת עורך דין לכל טקסטי הממצאים והעמודים המשפטיים
