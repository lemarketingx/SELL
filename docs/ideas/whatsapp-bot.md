# רעיון לשלב מאוחר: "דפדף בוואטסאפ"

> אחרי המעבר של תקין לשורש הריפו, הקוד של דפדף נמצא בתיקייה `dafdaf/` (למשל `dafdaf/api/generate.js`).

> סטטוס: רעיון שמור, לא בפיתוח.

## הרעיון

בעל עסק שולח לבוט הודעה קולית או טקסט, למשל: "אני מנעולן בפתח תקווה, 24/7, פריצת דלת 250 ₪".
תוך דקה הוא מקבל קישור לדף נחיתה מוכן, ויכול לעדכן אותו מהוואטסאפ:

- "תעלה מחיר ל-280"
- "תוסיף שאני עובד גם בשבת"
- שליחת תמונה עם הכיתוב "תשים בגלריה"
- לידים מהדף מגיעים אליו ישר לוואטסאפ

## מצב השוק (בדיקה קצרה, נובמבר 2026)

- בחו"ל קיימים כלים דומים: Macaly, Pixie, Nansi, Eezix.
- גרסה בעברית לא נמצאה בחיפוש קצר. זה לא סקר שוק מלא.

## ארכיטקטורה

```
הודעה קולית → WhatsApp Cloud API → /api/whatsapp (Vercel)
  1. הורדת ההקלטה דרך Graph API
  2. תמלול לעברית (OpenAI)
  3. זיהוי כוונה: דף חדש / עריכה / תמונה
  4. יצירה או עדכון של התוכן (מנוע היצירה הקיים)
  5. בניית HTML ושמירה
→ תשובה בוואטסאפ עם קישור לדף
```

## רכיבים נדרשים

1. **חשבון WhatsApp Business:** Meta Business מאומת, Cloud API ומספר ייעודי. רק ה-API הרשמי.
2. **`api/whatsapp.js`:** `GET` לאימות ה-webhook, `POST` להודעות, ואימות חתימה (`X-Hub-Signature-256`).
3. **תמלול:** הורדת המדיה ותמלול בעברית.
4. **זיכרון שיחה:** Upstash Redis, עם מפתח לפי מספר טלפון מגובב.
5. **יצירה משותפת:** הוצאת הלוגיקה מ-`api/generate.js` לפונקציה שגם האתר וגם הבוט משתמשים בה.
6. **⚠️ renderer בצד השרת:** היום ה-HTML נבנה בדפדפן (`js/builder.js`, `js/design-engine-v2-export.js` תלויים ב-DOM). צריך פונקציה שהופכת JSON למחרוזת HTML בלי DOM. זה החלק הכבד ביותר.
7. **אחסון ופרסום:** Vercel Blob או Redis, והגשה בנתיב `/p/[slug]`.
8. **עריכה בפקודה:** ה-AI מחזיר תיקון מובנה (`{ block, field, value }`), שעובר validation דרך `api/_validation.js`.
9. **לידים:** `/api/lead` ששולח הודעה לבעל העסק. מחוץ לחלון של 24 שעות צריך תבנית מאושרת, וזה בתשלום.

## עלויות (בקירוב, לבדוק מחירונים עדכניים)

- Meta: תשובות בתוך 24 שעות מהודעת המשתמש בחינם, והודעות תבנית יזומות בתשלום להודעה.
- OpenAI: תמלול ויצירה, בערך כמה סנטים לדף.
- Vercel / Upstash: בהיקף קטן כנראה מספיקות החבילות החינמיות.

## סדר עבודה מוצע

1. הוצאת לוגיקת היצירה ו-renderer בשרת, עם בדיקות.
2. שמירה והגשה של דפים בכתובת קבועה. זה שימושי גם לאתר הקיים.
3. בוט טקסט בסיסי.
4. הקלטות קוליות.
5. עריכה בפקודה ותמונות.
6. לידים ותבניות הודעה.
